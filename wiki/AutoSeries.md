# 自动追剧

自动追剧用于创建持久化追剧 Intent。系统会保存账号、目录、来源顺序、画质偏好和 Agent 协议快照，并在暂无资源或临时故障时继续巡检。

---

## 1. 功能概述

自动追剧会串联以下能力：

- **TMDB 识别**：根据剧集名称和年份匹配剧集信息、总集数、评分与状态。
- **CloudSaver 搜索**：自动搜索公开天翼云盘资源，并按标题、年份等信息给出候选资源。
- **影巢资源**：按 TMDB ID 查询天翼资源；自动流程只使用已解锁或零积分资源，绝不自动消费积分。
- **PT 回退**：聚合多个 PT/动漫 RSS 来源，结合近期文件样本、画质、版本与集数合理性创建持续订阅。
- **快速建任务**：使用系统预设的默认账号和默认保存目录创建任务。
- **媒体联动**：任务创建后可继续使用刮削、自动整理、STRM 和通知能力。
- **自主 Agent（默认关闭）**：按 Intent 启用，支持原生 Tool Calling 与 JSON 动作协议；`auto` 优先原生协议，不兼容时切换 JSON，AI 整体失败时回退确定性选源。
- **持久化巡检**：`no_coverage` 在北京时间每日 03:15 重新搜索，系统故障按 5 分钟、15 分钟、60 分钟、24 小时退避。
- **画质升级**：PT 同轮同集只选最高分版本，后续高分版本可升级，旧版文件与记录保留。
- **跨来源全季补齐**：Agent 会检查候选分享目录的实际季度/集数，用多个 CloudSaver、影巢或订阅资源拼出全季覆盖；每个任务只处理分配给它的集数，避免重复转存。

页面会显示 Intent 状态，并提供暂停、恢复与立即运行操作。实际文件整理仍完全由现有 Organizer 与 PT 整理器负责。

## 2. 前置配置

使用前请先完成两类配置。

### 2.1 自动追剧设置

进入 **自动追剧** 页，点击 **追剧设置**，集中设置：

| 配置项 | 说明 |
| :--- | :--- |
| 默认追剧账号 | 自动追剧创建任务时使用的天翼云盘账号 |
| 默认保存目录 | 资源最终转存或懒转存触发后的保存目录 |
| 默认追剧模式 | 懒转存或自动转存 |
| 来源与回退顺序 | 勾选并排序 CloudSaver、影巢、PT、订阅 |
| 影巢积分策略 | 是否允许积分资源及单资源积分上限 |
| Agent 与画质偏好 | 工具协议、字幕组、排除词及补充画质要求 |
| CAS 存根 | 恢复后是否保留 CAS 存根 |

如果未配置，自动追剧页会提示打开本页的“追剧设置”。

### 2.2 媒体与搜索配置

建议进入 **媒体** 页检查以下配置：

| 配置项 | 用途 |
| :--- | :--- |
| TMDB API Key | 提高剧集匹配和总集数识别准确度 |
| CloudSaver 设置 | 用于搜索可用分享资源 |
| STRM 设置 | 影响普通任务或懒转存任务的 STRM 生成 |
| AI 辅助重命名 / 媒体库分类命名 | 配合自动整理使用 |
| OpenAI 工具调用协议 | 设置新 Intent 默认使用的 `auto`、`native` 或 `json`；创建时仍可单独覆盖 |

## 3. Web 端使用

### 3.1 添加追剧

1. 进入 **自动追剧** 页。
2. 点击 **添加追剧**。
3. 填写 **剧集名称**。
4. 可选填写 **年份 (可选)**，用于区分同名剧集。
5. 可选开启 **手动选择资源**。
6. 点击 **开始追剧**。

模式、来源顺序、Agent、影巢积分和画质偏好都从独立的“追剧设置”读取，添加弹窗不再重复展示。设置由 Web、Telegram Bot 和榜单订阅共用。

### 3.2 手动选择资源

如果希望确认系统选中的资源：

1. 在添加追剧弹窗中勾选 **手动选择资源**。
2. 点击 **搜索资源**。
3. 在 **选择资源** 页面查看 CloudSaver 与影巢候选结果。
4. 参考 **匹配度**、资源标题、分享链接和 TMDB 信息选择资源。
5. 点击 **使用该资源创建任务**。

手动选择资源不是手动粘贴分享链接，而是从系统搜索到的候选资源中选择一个更合适的结果。

PT 不进入网盘候选列表。当前面的网盘来源未成功时，系统自动对 PT RSS 文件样本评分；AI 可用时会辅助判断标题、集数、画质和版本，AI 不可用或输出无效时自动降级为确定性评分。默认优先 2160p/4K、HDR/Dolby Vision、Remux/BluRay，其次 1080p，并降低预告、样片、错误季度和无关合集的优先级。

手动候选的恢复信息只保存在服务端：CloudSaver 分享链接加密落库，影巢保存 slug，订阅来源保存已校验的资源 ID。Intent 列表和 WorkflowRun 不返回裸分享链接；工作流审计中的 URL、Token 和 API Key 会脱敏。

## 4. 两种模式说明

| 模式 | 适合场景 | 行为 |
| :--- | :--- | :--- |
| 懒转存 (生成STRM) | 想先入库，播放时再占用网盘空间 | 创建懒 STRM 相关任务，播放时触发转存并换取直链 |
| 自动转存 (下载文件) | 希望资源立即进入网盘 | 创建普通转存任务并立即执行 |

懒转存模式要求默认账号已经配置本地 STRM 目录，否则系统会提示无法执行懒转存。

## 5. 创建后的默认行为

自动追剧创建的任务默认会带有以下任务信息：

- 任务分组：`自动追剧`
- 备注：`自动追剧`
- 普通模式：启用刮削、自动整理，不启用懒 STRM
- 懒转存模式：启用懒 STRM、自动整理，不启用任务刮削

实际任务执行结果仍以任务列表和日志为准。

启用 Agent 且 TMDB 能返回各季集数时，系统会按以下顺序处理“全季”请求：

1. 搜索所有已启用来源。
2. 递归读取候选分享目录，识别 `S01E01`、`Season 01`、`第 1 季`等季集信息。
3. 由服务端生成最少候选优先、媒体评分次优先的覆盖方案。
4. 为不同来源创建独立任务，但统一写入同一剧集媒体库布局。
5. 部分候选提交失败时保留已成功任务，将 Intent 标为 `no_coverage`，次日只针对仍缺少的集数继续搜索。

覆盖方案和缺集列表由服务端校验，AI 只能选择已检查过的候选，不能自行提交链接、目录 ID 或编造集号。TMDB 缺少季度集数时，系统不会猜测全季边界，而是回退到单资源追剧方式。

PT 画质升级只有在新文件上传完成、覆盖生成 STRM 并回读验证成功后，才会激活新版本并将旧版本标为非活动。任何验证失败都会保留旧版本的活动状态。

## 6. 状态与审计

Intent 常见状态：

| 状态 | 说明 |
| :--- | :--- |
| `pending` / `searching` | 等待执行或正在搜索 |
| `active` | 已关联普通任务或 PT 订阅 |
| `no_coverage` | 当前无可用覆盖，次日北京时间 03:15 再巡检 |
| `retry_wait` | 系统故障，按退避时间重试 |
| `failed` | 鉴权、权限或参数问题，需要人工处理 |
| `paused` | 已人工暂停 |

WorkflowRun 会记录实际工具名称、采用协议、媒体偏好评分、PT 正则样本验证摘要和确定性降级原因，便于验收执行路径，同时不保存裸资源链接和密钥。

## 7. Telegram Bot 使用

Telegram Bot 也支持创建追剧任务：

```text
/series 剧名 年份
```

示例：

```text
/series 庆余年 2024
```

创建懒转存追剧：

```text
/lazy_series 剧名 年份
```

Bot 追剧同样会使用 **自动追剧 → 追剧设置** 中的默认账号、目录和选源策略。

## 8. 常见问题

### 搜索不到资源怎么办？

- 确认 **媒体** 页中的 CloudSaver 配置可用。
- 使用更准确的官方剧名。
- 添加年份，例如 `庆余年 2024`。
- 换用常见别名或原始标题再次搜索。

### 选到的资源不对怎么办？

创建时勾选 **手动选择资源**，在候选列表中按标题、年份、匹配度和分享链接选择。

### 懒转存失败怎么办？

检查默认账号是否配置了本地 STRM 目录，并确认 **媒体** 页的 STRM 设置已按需要启用。

---

## 使用建议

- 同名剧集尽量填写年份。
- 首次使用建议勾选 **手动选择资源**，确认搜索质量后再使用自动选择。
- 自动追剧依赖 CloudSaver 和 TMDB，搜索失败时优先检查这两个配置。
